Why this file will not trigger the portal's range error

The portal error “Predicted values must be in range [0, 1]” has two known causes, both eliminated here (mechanisms measured by GEMSDOE32):

  • Values outside [0,1] — every one of the 12,279,160 cells of this raster was re-read from disk after writing: footprint cells min 0.0 / max 1.0; outside-footprint cells 0.0 (zeros file) or NaN (twin).
  • A nodata sentinel tag such as −3.4028234663852886e+38 — this file is written with no nodata tag at all; every cell is finite in the primary file.

Independent re-read receipts: evidence/format_receipts.json (sha256, geometry, range, checks) — all checks PASS.
