Metric, holdout protocols, and candidate-artifact audit

Official metric and catalogue mask

The official DrivenData metric page specifies a distance-weighted Tversky index with a triangular 300 m kernel, α=0.2, and β=0.8. The PR #1 implementation's TP/FP/FN arithmetic, distance transform and mask application reproduce the published definitions. Mask semantics are independently confirmed by DrivenData staff, forum 11516 post 4: only training-label pixels themselves are masked; nearby pixels remain penalized if far from new-fault truth; new-fault labels can be within 300 m of a known trace.

A local score against public known-fault labels is an instrument reading, not a leaderboard score and not validation against private expert labels.

Separate PR #1 candidate: four-fold component holdout

PR #1's reported setup hides about 25% of 8-connected catalogue components within each of four quadrant strata. The same full-domain 40,000-dot prediction is scored once per fold, against each fold's hidden truth while residual catalogue pixels are masked. The final artifact's DTI was independently recomputed exactly: 0.02026648, with fold DTI 0.03650436 / 0.01260255 / 0.01601234 / 0.01594669.

Why this does not pass the spatial-block gate: components are sampled within quadrants, not held out as whole geographic blocks; off-label false-positive mass outside a quadrant is scored in each fold; and NMS receives the full catalogue, so even the components treated as held-out truth are suppressed at prediction time. The truth pixels are subsequently unmasked for scoring. This is a component-sampled catalogue proxy—not the specified independent spatial hide-and-recover test.

Task-branch H49-XG: five spatial blocks, gate failed

The separate task-branch H49-XG primary used five buffered east–west blocks, fixed 37,654 mass, and a preregistered −0.01 maximum negative paired-fold delta. It scored pooled DTI 0.10041455 versus 0.08193976 for the strongest single-layer baseline. Four blocks won, but one paired difference was −0.01180243; therefore the preregistered gate failed. The 2 km-FWHM sensitivity cannot be selected on the same locked labels. This experiment generated no TIFF.

Whole geological segment IDs were unavailable. A post-run connectivity check found 21 raster components spanning two scored block cores (850 positive pixels); raster connectivity is not authoritative geological segmentation. See the result memo and primary receipt.

Gravity-support warning

The official USGS regional geophysics release linked from INGENIOUS GDR 1391 says its `GB_iso_grav_anom.tif` has 1 km cells. The competition mirror's band 13 has a matching name, but the exact lineage is unverified. Thus, 100 m raster spacing is not evidence of 100 m independent gravity observations, and the PR #1 candidate's 300 m σ requires revalidation at a conservative scale. The local autocorrelation/variance diagnostics measure mirror smoothness only, not native station spacing.

Uniqueness review: partial, not a final clearance

PR #1's JSON receipt reports 57 archived prior files, max smaller-set overlap 0.290125, and max signed Spearman −0.26557. The maximum absolute Spearman is about 0.98880 and is negative; “maximum signed” must not be read as “maximum absolute.” Three original artifacts were not available and the corpus/manifest is not tracked in this checkout.

The most relevant direct pair was rechecked independently against the pinned H33-2-B2 Git blob: H33 hash `c55bafc470054e8271dcb89347a17e07fefe50de6af6e6ba6c4b169ef7ab6fa9`; 792 shared pixels; overlap of smaller emission 0.021034; union Jaccard 0.010304; Spearman −0.979583. That pair is clearly different. This does not prove uniqueness against every prior file.
